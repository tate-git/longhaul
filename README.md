# 🌙 밤샘 운행 · Long Haul

**한국어** · [English](README.en.md)

3D 트럭을 몰고 고속도로를 달리는 장거리 운전 게임. 오후에 출발해 노을을 지나 밤에 도착합니다.

▶ **플레이: 아직 배포 전** — 아래 「실행해 보기」로 띄워 주세요.

## 소개

- 서울 → 대전 70km(게임 속 7km를 10배 시간으로) 구간을 뒤 시점으로 운전합니다.
- 하이패스 · 터널 · 휴게소 · 옆바람 부는 은빛대교를 지나 물류센터에 도착합니다.
- 폰·PC 둘 다 됩니다.

## 규칙

- 제한 속도 90km/h, 하이패스는 30km/h.
- 휴게소에서 15분 쉴 수 있습니다.
- 물류센터 초록 칸에 정차하면 끝 → 운행 일지와 ⭐ 평가.

## 실행해 보기

```sh
npx wrangler dev --port 8797
```

## 코드 구조

| 경로 | 내용 |
|---|---|
| `public/js/route.js` | 도로(굽이·경사·휴게소 등 위치·땅 높이) |
| `public/js/truck.js` | 트럭 물리(차선 유지 보조) |
| `public/js/world.js` · `sky.js` · `traffic.js` | 풍경 · 시간에 따른 하늘 · 다른 차 |
| `public/js/app.js` | 진행·화면 |

three.js 를 쓰고, 모델 파일 없이 전부 코드로 만듭니다.
